<objective>
A clinic saves its letterhead margins (header, footer, left, right in mm) once from the consultation area, and the shared print mechanism that will use them exists and can be proven with a test print (PRNT-01; decisions D-05, D-06, D-12).

Purpose: prescriptions are printed on pre-printed letterhead, so the body must stay inside the clinic's own blank area. Margins are per client, stored once, and applied as spacing (not browser page margins) so the browser's own header and footer text never lands on the letterhead.
Output: pure margin helpers verified by node, a tenant-scoped upsert query, a hook, a settings modal opened from the queue header, the shared `PrintSheet` + `usePrintJob` + print CSS (reused by plan 02-05 for prescriptions and by Phase 3 for receipts) and a Test print button.

Tracer note: Task 1 is the tracer: type four margins in the modal, save through the upsert, reload the page and see them again, wired through helper, query, hook, modal and tab. Task 2 expands to the shared print mechanism and the test print that proves the margins on paper.

**Prerequisite:** plan 02-01 Task 3 reported verified (the `print_settings` table with RLS and grants exists on live). Without it every load and save of this plan fails.
</objective>
