<objective>
A completed consult prints body-only (patient line, medications and notes, advice, follow-up) on pre-printed letterhead using the clinic's saved margins, from the queue, the editor and the patient history (PRNT-02; decisions D-06, D-10, D-11).

Purpose: the doctor prints the prescription after the consult is completed, and completed consults must never be silently reopened or un-completed. Today a Completed queue row is disabled and Save & Complete returns to the queue, so a completed consult has no way to be viewed or printed.
Output: `PrescriptionPrint`, a shared read-only summary extracted from the history recap, a Print button per Completed history row, a "View / Print" queue action and a read-only editor for Completed consults.

Tracer note: Task 1 is the tracer: a Completed row in Patient History is printed end to end (fetch, usePrintJob, PrintSheet, PrescriptionPrint, margins from settings). Task 2 expands to the queue entry, the read-only completed view and the shared summary.

**Prerequisites:** plan 02-04 (PrintSheet, usePrintJob, usePrintSettings, print CSS), plan 02-03 (AttachmentOpenButton) and plan 02-02 (vitals shown in the summary).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| database consultation text -> print DOM | Free-text clinical notes are rendered into the printed sheet |
| browser state -> printed paper | The printed payload is the one object handed to the sheet |
| read-only view -> write handlers | A Completed consult must not be mutable from this screen |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-02-24 | Tampering | clinical text rendered into the print DOM (script or markup injection) | medium | mitigate | all fields render as React text nodes; no raw HTML injection (static gate on the print file); whitespace preserved with CSS only |
| T-02-25 | Tampering | a Completed consult un-completed or altered via Save as Draft, Save & Complete, Cancel Consult or file actions from the view/print screen | high | mitigate | buttons and the upload control are not rendered when read-only and the handlers early-return on isReadOnly; startConsultation does not change a Completed status; human check confirms the row stays Completed |
| T-02-26 | Information Disclosure | app chrome, other patients or browser metadata printed with the prescription | medium | mitigate | PrintSheet portal plus the global print rule hide every other body child; the sheet contains only the selected consult's D-10 sections; page margin 0 removes browser header and footer text; verified in print preview |
| T-02-27 | Information Disclosure | the wrong patient's consult printed because of stale state | medium | mitigate | the payload is the exact ConsultationDetail fetched for the clicked visit (or the loaded active consult), passed through usePrintJob and cleared on afterprint; only Completed consults are accepted |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this phase (D-07); `git diff --name-only -- package.json package-lock.json` must be empty |
