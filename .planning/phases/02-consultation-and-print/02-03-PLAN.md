<objective>
Attachments upload to the private `consultation-files` bucket, are scoped by `client_id`, and open through short-lived signed URLs; legacy name+URL rows keep working (CONS-03; decisions D-03, D-04, D-12).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser file picker -> Storage bucket | Untrusted file bytes, name and declared type enter a private health bucket under the user's JWT |
| browser -> consultation_attachments | A stored file_url from legacy rows is rendered as a link |
