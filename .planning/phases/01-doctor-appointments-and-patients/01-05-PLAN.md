<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| customer row id -> consultation and attachment queries | A patient id taken from the clicked row selects which PHI is fetched |
| consultation_attachments.file_url -> anchor href | A stored URL string becomes a link the user clicks |
| browser storage | Drawer and open-patient state must not be persisted |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-01-23 | Information Disclosure | Visits and Files queries (another tenant's consultations or attachments) | high | mitigate | Every query filters `.eq("client_id", clientId)` with clientId from the authenticated tab context (never URL or row data); attachments are fetched only for consultation ids that came from the client-scoped consultations query; RLS via crm_can_access_client is the backstop |
| T-01-24 | Information Disclosure | Stale response shows patient A's allergies or visits inside patient B's drawer (clinical safety) | high | mitigate | Drawer body keyed by patient id; each panel effect uses a cancelled flag and cleanup; panels mount per tab |
| T-01-25 | Tampering | file_url rendered as an anchor (script or data URL execution on click) | medium | mitigate | Link only when the URL matches http or https; target _blank with rel noopener noreferrer; other values shown as plain text |
| T-01-26 | Information Disclosure | Attachment URLs are public and unsigned today | medium | accept | Existing upload behaviour outside this phase; Phase 2 (CONS-03) moves to a private client-scoped bucket with signed URLs; this drawer only lists what already exists |
| T-01-27 | Information Disclosure | Clinical data kept in localStorage via persistent state | low | mitigate | Drawer and open patient use plain useState; static check forbids usePersistentState in the patient components |
| T-01-28 | Spoofing | Drawer reachable by tenants without the consultation tab | low | accept | UI gate is a presentation rule only (D-11); data access is governed by RLS per tenant regardless |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this phase (D-16); `git diff --name-only -- package.json package-lock.json` must be empty |
</threat_model>
